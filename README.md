# Backend de Gestión de Hábitos (Atomic Habits)

Este proyecto es una API REST construida con **Node.js** y **Express** para la gestión de hábitos, conectada a una base de datos **MongoDB Atlas** mediante **Mongoose**.

## Requisitos Previos
* Node.js instalado.
* Una cuenta en MongoDB Atlas (o acceso al clúster configurado).

## Instalación
1. Clona o descarga este repositorio.
2. Abre una terminal en la carpeta raíz del proyecto.
3. Instala las dependencias necesarias ejecutando:
    npm install

## Configuración de Variables de Entorno
Crea un archivo .env en la raíz del proyecto (si no existe) y agrega tu cadena de conexión:
PORT=3001
MONGO_URI=tu_cadena_de_conexion_de_mongodb_atlas

## Ejecución
npm start
